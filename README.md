# GRANDSLAM — LoL 올타임 드래프트 시뮬레이터

랜덤 (팀 × 연도) 스핀으로 LoL e스포츠 역사 속 로스터를 받고, 한 명씩 드래프트해 5인 올타임 팀을 만든 뒤
2026 시즌(Split → MSI → Worlds)을 1초 만에 시뮬레이션하고 결과 카드를 공유하는 무료 웹 게임입니다.

- 서비스: https://grandslamlol.vercel.app (종료, 페이지는 열려 있음)
- 기간: 2026.06.11 ~ 06.14 3일 스프린트로 배포, 같은 달 종료
- 개인 프로젝트. 기획·데이터 수집·개발·홍보 혼자
- 결과: 방문자 1,137 · 재방문 세션 17% · 초기 스파이크 후 급감. 가설 실패로 접음

## 왜 만들었고 왜 접었나

당시 스포츠 쪽에서 스핀-드래프트-시뮬 포맷이 유행이었고 LoL 버티컬에는 자리 잡은 게 없었습니다.
가설은 **"재방문이 낮아도 공유만 되면 트래픽은 유지된다"**였고, 그래서 기능이 아니라 기간을 먼저 정해 3일 안에 냈습니다.

사람들은 공유 버튼을 안 눌렀습니다. 결과 화면을 캡처해서 커뮤니티에 올렸고, 이미지로 퍼지니 돌아올 길이 없었습니다.
공유 화면 안에 서비스 링크를 넣고 나서야 서비스명 검색 유입이 생겼는데 이미 유입이 꺾인 뒤였습니다.
제품 문제인지 시장 문제인지 가르려고 영어판을 만들어 해외 커뮤니티에 다시 올렸고, 결과가 같아 원인을 제품으로 잡고 종료했습니다.

여기서 확인한 조건(다시 올 이유가 먼저다, 공유 경로는 사용자 행동이 정한다)으로 다음 달에 [FC Detox](https://fcdetox.com)를 만들었습니다.

## 구조

```
src/
  app/          Next.js 15 App Router. / 스핀·드래프트, /draft, /r 결과 카드, /dex 선수 도감
  lib/          시뮬레이션(Elo 기반), 등급 컷, 시드 PRNG, 데이터 로더
  components/   PlayerCard, ResultCards 등
scripts/        데이터 파이프라인. 번호 순서대로 실행
  01~03         대회·로스터·경기 결과 수집
  04*           선수 레이팅(OVR) 산출과 보정
  05~06         선수 사진 수집 → Cloudflare R2 업로드
  07            정적 데이터 빌드
  09*           몬테카를로 검증 (그리디·랜덤 픽 각 10,000회, 등급 분포가 목표 범위에 드는지)
docs/           PRD, 게임 스펙, 디자인 가이드, 진행 로그
```

배포 전에 `scripts/09-montecarlo.ts`로 등급 분포(GRAND SLAM 3~8%, REBUILD ≤25% 등)를 확인하고 Elo 스케일을 튜닝했습니다.
화면과 같은 시뮬 코드를 돌리기 때문에 배포 후 "결과가 이상하다"가 나오면 여기서 먼저 재현합니다.

## 스택

Next.js 15 · React 18 · TypeScript · Tailwind CSS · Cloudflare R2 · Vercel

## 실행

```bash
npm install
cp .env.local.example .env.local   # R2 키. 없으면 선수 사진은 아바타로 폴백
npm run dev
```

## 고지

라이엇 게임즈와 무관한 개인 프로젝트입니다. 선수·팀 데이터는 공개 기록을 수집한 것이며, 코드의 재사용·재배포를 허락하지 않습니다.
